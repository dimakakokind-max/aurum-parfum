# AURUM | Премиальная Парфюмерия 💎

Добро пожаловать в **AURUM** — концептуальный веб-сайт, созданный для демонстрации люксовой парфюмерии. Проект сочетает в себе эстетику высокого бренда и современные веб-технологии.

## ✨ Особенности

*   **Эффект Glassmorphism:** Полупрозрачные карточки и навигация с размытием (backdrop-filter), создающие ощущение глубины.
*   **Интерактивный курсор:** Кастомная золотая точка с аурой, которая следует за мышью.
*   **Живые анимации:** Летающие стеклянные панели при клике, взрыв золотых частиц и «дыхание» карточек.
*   **Фильтрация:** Удобная система фильтров по категориям (Гурманские, Свежие, Вечерние, Древесные, Для неё, Для него).
*   **Модальные окна:** Всплывающие карточки товаров с описанием и ценой.
*   **Защита контента:** Отключено выделение текста для сохранения целостности дизайна.
*   **Адаптивность:** Корректное отображение на мобильных устройствах (курсор и лишние элементы скрываются).

## 🛠️ Технологии

*   HTML5 (Семантическая верстка)
*   CSS3 (Flexbox, Grid, Анимации, Backdrop-filter)
*   JavaScript (Vanilla JS, DOM-манипуляции, события)

## 🚀 Как запустить

Просто откройте файл `index.html` в любом современном браузере. Никаких сборщиков или зависимостей не требуется.
